# Datos

El CSV `meats.csv` se descarga automáticamente al ejecutar el notebook o `src/analisis_nir.py`.

Fuente: https://modeldata.tidymodels.org/reference/meats.html
CSV de trabajo: https://raw.githubusercontent.com/vincentarelbundock/Rdatasets/master/csv/modeldata/meats.csv

El dataset contiene 100 canales de absorbancia NIR y porcentajes de agua, grasa y proteína para 215 muestras. La fuente original indica que los datos pueden redistribuirse si se adjunta la nota de permiso y se atribuye el equipo Tecator. Consulte `docs/atribucion_dataset.txt`.
